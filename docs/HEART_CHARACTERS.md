# 심장 캐릭터 기준안

## 공통 흐름

- 마을에서 해당 귀신과 대화해 심장을 빌린다.
- 심장을 빌리면 외형, 최대 HP, Q 심장 스킬이 바뀐다.
- 해당 귀신의 낮은 등급 기본 주무기를 즉시 받는다.
- 죽거나 새로 마을에 도착하면 검은 인간 형태로 돌아가며 심장을 다시 골라야 한다.

## 손각시

- 최대 HP: 60
- 기본 무기: 손각시의 손
- Q: 이리 오너라 — 시야 안 적을 머리카락으로 끌어온다. 재사용 30초.

## 몽달귀신

- 해금: 처음부터 선택 가능
- 최대 HP: 90
- 기본 무기: 몽달의 손톱
- 심장 스킬 없음
- 기본 대시 1회에 2회가 추가되어 최대 3회까지 연속 사용한다. 사용한 대시는 0.65초마다 한 칸씩 회복한다.
- 전투 성격: 높은 체력과 빠른 연타, 연속 대시를 이용한 추격형.
- 외형 기준: 혼례를 치르지 못한 남성 귀신, 미완성 혼례복, 산발, 부러진 목각 기러기 모티프.

## 창귀

- 해금: 장산범 처치 후
- 최대 HP: 70
- 기본 무기: 범의 발톱
- Q: 창귀원혼 — 맵에 살아 있는 모든 몬스터에게 푸른 원혼이 들러붙어 4초간 완전히 정지시킨다. 재사용 30초.
- 전투 성격: 낮은 체력을 감수하고 방 전체를 멈춰 공격 기회를 만드는 군중 제어형.
- 외형 기준: 갓 없는 일반 농노, 산발, 삼베옷, 한쪽 팔과 반대쪽 다리 결손, 백골 노출, 배의 호랑이 발톱 상처.

## 아트 상태

- 이미지 생성 초안 `*-heart-atlas-draft-v1.png`를 게임용 시트로 정리해 몽달귀신은 `assets/actors/source/mongdal-v1.png`, 창귀는 `assets/actors/source/changgui-v1.png`로 연결했다.
- 두 시트는 손각시와 같은 1536×1024, 8열 × 4행 규격이다. 한 프레임은 192×256이며 발 위치가 셀 아래쪽에서 흔들리지 않도록 정렬했다.
- 행 구성은 idle, move, attack, jump/dash·hurt·death 순서다. 현재 이미지는 1차 적용본이며 세부 동작과 잔상은 이후 아트 다듬기 대상이다.
- 창귀원혼 효과는 `pixelfx`의 `geuseundae/changgui-soul-bind`로 제작했으며 PNG와 JSON 시트로 내보낸다.
