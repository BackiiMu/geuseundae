# 장비 구현 및 직접 검수

현재 실제 목록은 무기 35개와 비무기 장비 10개, 총 45개다. 손각시 심장은 별도 고정 슬롯이며 몽달귀신·창귀 심장도 플레이 캐릭터로 연결되어 있다.

## 구현

- 손각시: 세 번째 머리카락 속박, 벽에 꽂힌 비녀의 접촉 지대, 댕기 단일 끌기, 족두리 산탄과 다음 피격 증폭.
- 달걀귀신: 껍데기 산탄, 전방 원뿔 공포, 유지형 광선과 점진 둔화·광선 방향 공포.
- 몽달: 실제 연속 적중에 따른 손톱 가속, 기러기 왕복 재타격, 돌진 경로 타격.
- 창귀: 세 발톱 타격, 지속 집결 지대, 처치한 넋 최대 3개 동료 소환, 도약 물기와 호랑이 혼령 관통 돌진.
- 물귀신: 포물선 물덩이와 둔화 웅덩이, 발목 둔화, 두레박 범위 타격과 지속 흡인 우물.
- 구미호: 공전 구슬과 약한 유도, 아홉 번째 꼬리 강타, 접근 지뢰 3개, 피격·폭발하는 허상과 짧은 순간이동.
- 도깨비: 추가 조각 확률, 불규칙 불꽃, 떠다니는 빗자루 보조 평타, 실제 적 던지기와 충돌 피해·메치기.
- 추가 귀신: 이빨 8발 재장전, 혀 끌기와 실제 피해 비례 회복, 주변 적에 따른 그림자 범위, 혼란과 적끼리 공격, 포물선 독 지대, 벽 관통 음파, 삼킨 적 수를 소비하는 뱉기.
- 두억시니: 0.3초 준비 후 주먹 타격·이동 가능·히트스톱, 사거리/탄 크기 머리 조각, 대시 피해 저주, 3종 완성 G 짓누르기.
- 일반 장비 8개: 가발, 두??니??의 XX??, 꺾인 다리, 몽달의 다리, 젖은 꽃신, 한쪽 꽃신, 아귀의 위장, ??의 짙은 저주. 기존 효과와 장착·교체·파기를 유지했다.

## 장비 시험장

- 화면의 `장비시험 [F6]` 버튼 또는 F6로 출입한다.
- 원래 가방·재화·장착·체력·시드·방을 보관하고 복귀 시 복원한다. 미클리어 방의 적은 원래 방 배치로 다시 생성된다.
- 시험장 가방은 41개 전체 장비를 제공한다. 시험품은 일반 진행에 반출되지 않는다.
- `[` / `]`: 무기 순서 전환. 보조무기는 머리카락 주무기와 함께 시험한다.
- T: HP120 표적 3기와 쿨타임 초기화. P: 두억시니 3종 장착. Tab: 일반 장비도 직접 장착.
- J는 바라보는 방향, 좌클릭은 마우스 조준 공격이다. F/G는 마우스로 조준하며 J를 함께 누르면 바라보는 방향으로 사용한다.
- 시험장만 피격 피해를 막고 고정 표적을 사용한다. 일반 던전은 정상 AI·피격 규칙을 유지한다.

## 검수

- `equipment_test.gd`: 41개 ID·설명, 전 무기 공격/스킬, 속박·연타·주먹 준비·광선·왕복 재타격·재장전·피격 증폭·넋·던지기 충돌·삼키기/뱉기·허상·두억시니 세트와 일반 장비 효과, 시험장 복귀를 검사했다.
- Godot Web 640×360 화면에서 33개 무기를 모두 전환해 J와 F/G를 사용했다. 짧은 근접은 접근해서 확인했다. 넋과 삼키기/뱉기는 표적 처치 후 추가 확인했다. 일반 장비 8개도 장착·교체했다.
- 최종 일반 회차: 마을 → 결계 숲길 → 오래된 신당 → 봉인된 창고(6조각 구매) → 끊어진 회랑 → 보스 처치 → 30조각·장비 보상 수령 → 2층. 여우구슬·물귀신 손·가발로 HP18, 영혼조각34를 남겼다. 이 회차에 F8이나 시험장 장비는 사용하지 않았다.
- 검수 중 포물선이 바닥 도달 전에 만료되던 문제를 수정하고 웅덩이 생성 검사를 추가했다.
- 기존 전투·실시간 AI·상점·8방향 대시·하강·심장 다중 대상 검사도 통과했다.

수치와 쿨타임은 데모 조정값이다. 캐릭터·몹·일부 아이콘과 공격 그림은 임시 도형이다. 최종 애니메이션·음향·저장 시스템까지 완성한 것은 아니다.
