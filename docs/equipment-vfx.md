# 장비 등급별 픽셀 이펙트

2026-11-03. pixelfx 스킬과 로컬 라이브러리를 사용했다. 아래 기록 중 금빛 전설 주먹은 사용자 피드백 후 폐기하고 검은 그림자 주먹으로 교체했다.

## 사용자 피드백 반영: 그림자 주먹과 원본 연출

- 실제 pixelfx 사이트에서 Shadow → Dark explosion을 열어 느린 재생으로 확인했다. 기존 단순 도형의 밀도·형체 변화가 원본 수준에 못 미쳤음을 확인했다.
- 두억시니는 `geuseundae/shadow-fist.js` 전용 이펙트로 교체했다. 검은 불투명 몸체, 비대칭 주먹 관절과 말아 쥔 엄지, 제한된 회청색 윤곽, 풀리는 손목 리본, 검은 연기와 파편을 사용한다. 금색 손은 사용하지 않는다.
- 세 번 렌더링해 손가락 구분, 불투명한 몸체, 소멸 시 바둑판 구멍 대신 흐르는 침식을 조정했다. pixelfx 검사도 통과했다.
- 베기·명중·상위 폭발·문양은 사이트의 원본 sword-slash, double-slash, scythe-reap, heavy-cleave, hit-spark, blunt-hit, crit-hit, dark-explosion, hex-sigil 연출을 시간 구간과 색만 조정해 직접 내보낸다. 광선도 arcane-beam 원본을 쓴다.
- 최종 출력은 23개 프로필이다. JSON manifest의 `source`에 원본 출처를 기록하며, `anchor`로 실제 명중 중심을 맞춘다. 기존 22개 고정 크기를 전제로 하지 않는다.
- 실행 화면에서 검은 주먹의 맵 대비와 새 광선을 검수하고, 장비 검사 106개 및 VFX 리소스 검사를 다시 실행했다.

## 연출 방향

- 일반: 짧은 한 겹 궤적, 작은 발사점, 적은 색. 주변 반짝임 없음.
- 희귀: 선명한 외곽, 짧은 잔상과 소수 파편.
- 영웅: 겹친 궤적, 깨진 문양, 별 모양 파편. 광선은 어두운 외곽과 밝은 중심으로 구분.
- 전설: 어두운 본체에 제한된 금빛·백색 광점, 큰 명중 파편과 분리된 충격선. 두억시니 주먹·세트 짓누르기·호랑이 혼령은 별도 형체.

공통 모티프를 등급별로 재사용하고 장비 계열 색을 입힌다. 장비마다 완전히 별개의 애니메이션 41종을 만든 것은 아니다. 심장 머리카락은 움직이는 적을 따라 기존 절차형 선으로 연결하고 영웅급 발동 문양을 덧붙였다.

## 파일과 재생

- 원본: `vendor/pixelfx/src/fx/geuseundae/equipment-strike.js`.
- 재생성: pixelfx 폴더에서 `node tools/export-geuseundae.mjs`.
- 출력: `godot/assets/vfx/` 투명 PNG 23장과 프레임·피벗 manifest.
- Godot: `pixel_vfx.gd`에서 nearest 필터로 재생. 왼쪽은 수평 반전해서 주먹이 뒤집히지 않게 한다.
- 일반 공격은 짧게 재생하고 전설 주먹은 준비 후 타격 시점에 등장한다. 기존 피해·쿨타임·판정은 유지했다.
- 발사체, 지속 지대, 광선은 움직이는 좌표에 맞춰 재생한다. 적의 주황색 공격 표시는 유지한다.
- 동시 일회성 이펙트는 최대 40개, 같은 적 명중 효과는 0.09초 간격. 가방·상점·히트스톱·순간정지 때 함께 멈추고 방 이동 시 제거한다.

## 검수

- 횃불·베기·그림자 촉수·물 튀김·치명타 라이브러리를 렌더링해 참고했다.
- 일반 베기와 전설 주먹을 3회 렌더·시각 검수하며 색, 잔광, 손가락 구분을 수정했다.
- pixelfx 검사 통과. Godot 장비 검사 106개와 VFX 리소스·등급 선택·반전·수명·정지·전환 검사를 통과했다.
- 실제 640×360 Godot Web 실행 화면에서 일반 베기, 희귀 비녀, 영웅 광선/공포, 전설 주먹과 3대상 짓누르기를 확인했다. 일반 궤적이 바닥 아래로 내려가던 위치를 수정했다.
- 시험장 F9로 이펙트 프레임을 멈추거나 재개할 수 있다. T는 표적과 이펙트를 초기화한다. F6는 원래 진행으로 복귀한다.

## 장비 아이콘

2026-11-04. 게임 UI와 같은 42×42 원본 크기를 사용해 축소 흐림을 없앴다. 손각시 4종은 사용자 피드백을 거쳐 6~7색, 재질 명암 3단계, 핵심 장식과 보조 디테일 하나씩을 남기는 중상 밀도 기준으로 확정했다. 나머지 37종은 형태 구분용 초안이며 순차 교체 대상이다.

- 원본: `vendor/pixelfx/src/fx/geuseundae/equipment-icon.js`.
- 재생성: `node vendor/pixelfx/tools/export-equipment-icons.mjs`.
- 출력: `godot/assets/equipment/icons/`의 투명 PNG 41개와 manifest.
- 적용: `item_icon.gd`가 장비 ID에 맞는 아이콘을 가방과 도깨비상점에 표시한다.
- 검수: 세 차례 다시 렌더링해 도깨비불/여우불, 피 묻은 족두리/둔갑 거울, 손각시 머리카락/몽달 손톱/범의 발톱, 추상 장비의 중심 귀물을 분리했다. pixelfx 검사와 장비 행동 검사 전체를 통과했다.

캐릭터·몹 외형과 음향은 이번 이펙트 작업의 범위가 아니다. 화면 전체를 번쩍이는 효과나 새 공격 판정은 추가하지 않았다.
