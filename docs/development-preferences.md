# 개발 중 화면 표시 선호

- 사용자는 현재 큰 게임 창을 띄우기 곤란한 상황이다.
- 현재 축소한 Godot 창을 이동하거나 확대하지 않는다. 현재 실행 중인 창을 그대로 사용한다.
- 다음 실행 시 기본 게임 화면은 640×360으로 제한한다. 논리 게임 해상도와 이동·점프 설정은 유지한다.
- 현재 창 위치도 사용자 지정 상태를 존중한다. 위치 좌표는 아직 수집하지 않았으므로 재실행 때 자동 중앙 배치가 현재 위치를 보존한다고 가정하지 않는다. 불필요한 재실행·새 창 열기를 피한다.
- 나중에 사용자가 요청하면 확대할 수 있다.
