# 그슨대 1~6챕터 및 일반 엔딩 설계안

> **상태: 제안·설계 문서.** 현재 구현 완료를 뜻하지 않는다. 1~3챕터의 기존 구현을 바탕으로 4~6챕터와 로그라이크 반복 서사를 설계한 안이다.

## 1. 전체 구조

- 총 6챕터. 성공 회차는 반드시 1챕터에서 시작해 6챕터를 연속으로 진행한다.
- 챕터마다 시드 기반 9개 방 지도를 생성한다. 모든 방 방문은 선택이며 최단 경로는 일반 전투 3~4회, 평화방 1회, 보스전 1회 정도를 목표로 한다.
- 목표 플레이 시간은 빠른 진행 35~45분, 일반 탐험 50~65분, 전 방 탐험 70분 이상이다.
- 사망하면 흉가로 돌아가 심장을 다시 빌리고 1챕터부터 재시작한다.
- 맵·상점·장비·영혼조각·방 클리어는 회차 단위로 초기화한다.
- 해금한 심장, 발견 장비 풀, 보스 최초 처치, 구출 NPC, 기억 조각, 최고 도달 챕터는 영구 유지 대상으로 둔다.

### 로그라이크 반복의 세계관

대퇴마사가 `귀록`에 기록된 귀신의 이름과 약점을 이용해 `회귀진`을 작동시키고 있다. 의식이 완성되기 전까지 흉가가 습격당한 밤 전체가 반복된다. 귀록에 기록된 인간과 귀신은 회차가 돌아간 사실을 기억하지 못하지만, 이름이 기록되지 않은 그슨대만 이전 회차를 기억한다.

그슨대가 쓰러지면 빌린 심장과 모습이 깨지고 흉가에 묶인 검은 본체만 밤의 시작점으로 돌아온다. 회귀진이 불완전하기 때문에 영로와 방 연결은 매번 달라진다.

## 2. 공통 챕터 구성

| 방 역할 | 기준 |
|---|---|
| 시작방 | 안전한 진입과 챕터 소개 |
| 일반 전투방 | 챕터 고유 적 조합과 지형 학습 |
| 정예방 | 챕터 기믹을 강화한 선택 전투 |
| 구조·기억방 | 포로 구출 또는 그슨대의 과거 단서 |
| 보상방 | 상자, 장비, 회복 중 하나 |
| 평화방 | 챕터마다 반드시 1개, 도깨비상인 배치 |
| 보스방 | 최종 목적지. 기존 문 형태의 보스전 입구 사용 |

우물은 현재 회차의 상세 지도를 확인하고 이미 발견한 방으로 이동하는 장치다. 우물 이동은 방을 클리어하지 않으며, 보스방으로 직접 이동할 수 없다.

## 3. 1챕터 — 흉가

### 서사 목적

- 귀신들의 집이 인간 퇴마단에게 공격받는다.
- 귀신들은 약점이 모두 기록되어 있지만 신참 귀신 그슨대만 기록에 없다는 사실을 소개한다.
- 그슨대가 심장을 빌리고 처음 싸우는 과정을 보여준다.

### 공간과 동선

- 무너진 한옥, 앞마당, 행랑채, 우물, 신당, 곡간, 대숲.
- 가장 단순한 지상 동선에서 시작해 낮은 발판과 작은 벽을 순서대로 소개한다.
- 위험한 낭떠러지나 복잡한 수직 전투는 최소화한다.

### 일반 적

| 적 | 역할 |
|---|---|
| 퇴마 무사 | 기본 근접 추격과 베기 |
| 부적 도사 | 직선 부적 투사체, 후방 유지 |
| 목탁 승려 | 느린 근접 충격파와 전선 유지 |

### 보스 — 퇴마단 선봉대장

- 넓은 베기, 내려베기, 돌진으로 기본 회피를 종합 검사한다.
- 최초 처치 시 퇴각하는 퇴마단을 추격하는 이야기 장면을 재생한다.
- 반복 처치에서는 장면을 생략하고 보상만 제공한다.

### 최초 클리어 보상

- 2챕터 진입 연출 해금.
- 첫 보스 장비 풀 해금.

## 4. 2챕터 — 안개 낀 산

### 서사 목적

- 퇴각한 퇴마단을 추격한다.
- 인간들이 귀신과 짐승을 봉인해 전투 도구로 사용한다는 사실을 처음 보여준다.
- 이 챕터의 귀신형 적은 자발적으로 싸우는 존재가 아니라 부적·방울·쇠사슬로 조종당하는 존재다.

### 공간과 동선

- 안개 능선, 절벽, 동굴 입구, 썩은 나무다리, 폐암자, 호랑이 굴.
- 넓은 낭떠러지, 위아래 발판, 시야를 가리는 옅은 안개를 사용한다.
- 썩은 나무다리는 바닥 협곡을 건너는 실제 발판이며 장식으로 띄우지 않는다.

### 일반 적

| 적 | 역할 |
|---|---|
| 창귀 잔혼 | 봉인된 빠른 근접 돌진 |
| 미혹불 | 조종 부적을 단 추적 투사체형 |
| 호식총 원귀 | 고정형 또는 느린 지면 범위 공격 |
| 산호랑이 | 빠른 도약과 할퀴기 |
| 장산범 그림자 | 정예. 빠른 이동과 넓은 공격 |

적이 쓰러질 때는 소멸보다 봉인이 깨지고 원혼이 빠져나가는 연출을 우선한다.

### 보스 — 장산범

1. 플레이어와 같은 모습, 기본 할퀴기만 사용.
2. 장산범 그림자, 크기와 속도 증가.
3. 흰 몸·붉은 얼굴의 장산범 본체.

각 페이즈는 별도 체력을 가지며 처치 시 안개가 보스를 가리고 다음 모습으로 전환한다.

### 최초 클리어 보상

- 장산범의 봉인을 해제한다.
- 장산범 장비 중 하나 지급 및 장비 풀 해금.
- 창귀 심장 해금.

반복 회차의 장산범은 실제 장산범이 다시 붙잡힌 것이 아니라 귀록이 재현한 기록으로 취급한다.

## 5. 3챕터 — 퇴마단 주둔지

### 서사 목적

- 그슨대가 인간 진영으로 본격적으로 침투한다.
- 붙잡힌 귀신들이 어딘가로 운반되고 있다는 사실을 발견한다.
- 회귀진과 귀문 수용소에 대한 첫 직접 단서를 얻는다.

### 공간과 동선

- 군영 입구, 훈련장, 궁수 망루, 병기고, 감옥 마당, 금줄 제단.
- 평지 진형과 높은 감시대가 함께 있는 혼합형 구조.
- 장식보다 실제로 밟을 수 있는 망루·지붕·목책을 늘린다.

### 일반 적

| 적 | 역할 |
|---|---|
| 퇴마 창수 | 도약 후 내려찍기 |
| 퇴마 궁수 | 위에서 떨어지는 3연속 화살 |
| 방울 술사 | 바닥 금줄 봉인과 이동 제한 |
| 사냥매 | 약한 공중 적, 대각선 급강하 |

### 선택 목표 — 포로 구출

- 일부 방은 적 처치 후 감옥을 열 수 있다.
- 최초 구출 귀신은 귀록에서 이름이 찢겨 나가 흉가 NPC로 합류한다.
- 이후 회차의 같은 자리는 빈 감옥, 회복, 영혼조각 또는 다른 포로로 대체한다.

### 보스 — 쇄혼대감

- 기본 공격: 넓은 베기, 봉인목 내려베기, 쇠사슬 돌진.
- 쇄혼 포획: 2초 제한의 4연타 구슬을 3~5회 처리.
- 삼중 봉인: 말뚝 3개가 최대 HP·대시·심장 능력을 제한.
- 심장 적출: 체력 30% 이하에서 부적 낙하 회피.
- 모든 특수 패턴은 봉인목에서 원혼을 강제로 끌어내는 공통 모션으로 시작한다.

### 최초 클리어 보상

- 귀문 수용소로 내려가는 지하문 발견.
- 이름이 지워진 어린아이에 대한 첫 기록 조각 획득.

## 6. 4챕터 — 귀문 수용소

### 서사 목적

- 퇴마단이 귀신을 봉인하고 영혼조각·장비·부적의 재료로 사용한다는 사실을 확정한다.
- 그슨대가 퇴마 의식에 휘말려 죽은 기록 없는 아이라는 단서를 단계적으로 공개한다.

### 공간과 동선

- 축축한 지하 석벽, 목조 감옥, 봉인 화로, 수로, 고문실, 승강 우리.
- 좁은 수평 통로와 높이가 크게 다른 감옥층을 연결한다.
- 철창·승강 우리·파괴 가능한 자물쇠가 실제 동선에 영향을 준다.

### 일반 적

| 적 | 역할 |
|---|---|
| 쇠사슬 포졸 | 갈고리로 플레이어를 끌고 곤봉 공격 |
| 방패 군졸 | 정면 방어, 뒤·위 공격에 취약 |
| 화로 술사 | 바닥을 따라 퍼지는 불길로 구역 통제 |
| 봉인등 지기 | 갇힌 원혼으로 추적 표식 생성 |
| 추적견 | 낮은 자세의 빠른 돌진과 짧은 붙잡기 |

### 정예 — 귀갑 집행관

- 등에 작은 귀신 감옥을 짊어진 대형 인간.
- 정면을 방어하며 뒤의 봉인핵이 약점이다.
- 감옥 속 원혼을 한 번 소모해 체력을 회복한다.

### 보스 — 귀문옥주

| 패턴 | 내용 |
|---|---|
| 철창 폐쇄 | 양쪽 철창이 좁혀오며 제한시간 안에 자물쇠 파괴 |
| 장비 봉인 | 심장을 제외한 장착 부위 하나를 임시 봉인, 봉인패 파괴 시 복구 |
| 원혼 형벌 | 쇠사슬 3개를 끊으면 원혼이 보스를 공격, 실패 시 보스 회복 |
| 감옥 붕괴 | 체력 30% 이하에서 전장을 수직 발판 구조로 변경 |

### 최초 클리어 보상

- 수용소 봉인목록 파괴.
- 그슨대의 죽음에 관한 두 번째 기억 조각.
- 신규 심장 캐릭터 후보 구출. 대상은 별도 확정한다.

## 7. 5챕터 — 도성 성곽

### 서사 목적

- 회귀진과 귀록이 대신당에서 작동한다는 사실을 확정한다.
- 인간 진영의 최종 방어선을 돌파한다.
- 민간인은 이미 대피한 상태로 두며 전투 대상은 퇴마단과 군졸로 한정한다.

### 공간과 동선

- 성하 거리, 기와지붕, 성벽, 망루, 성문 내부, 오방 결계탑.
- 지붕 위 전투와 성벽 내부 통로를 번갈아 배치한다.
- 사다리, 지붕, 성문 위가 실제 발판으로 기능한다.

### 일반 적

| 적 | 역할 |
|---|---|
| 금위 방패병 | 좁은 통로를 막고 정면 방어 |
| 성벽 궁수 | 높은 지형에서 곡사 공격 |
| 쇠뇌 술사 | 긴 예고 후 벽에 막히는 고속 관통탄 |
| 오방기수 | 주변 적 강화, 우선 처치 대상 |
| 결계 판수 | 일정 구역에 정화 장판 생성 |
| 사냥매 정예 | 급강하 후 다시 고지대로 복귀 |

### 방 기믹

- 오방 결계탑을 파괴하면 적 강화 해제.
- 성벽 화살은 바닥에 명확한 예고선을 표시한다.
- 일부 벽은 일반 투사체와 캐릭터를 막지만 파괴형 공격으로 부술 수 있다.

### 보스 — 금위퇴마대장

- 오방진의 색에 따라 공격 속성과 안전지대가 변한다.
- 진을 하나씩 파괴할 때마다 방어가 해제된다.
- 마지막에는 성문 위 좁은 지형에서 소환 없는 일대일 근접전으로 전환한다.

### 최초 클리어 보상

- 대신당 진입로 개방.
- 귀록과 회귀진의 존재를 명확히 확인.
- 그슨대가 귀록에 없는 존재라 대퇴마사가 대응하지 못한다는 단서 획득.

## 8. 6챕터 — 대신당

### 서사 목적

- 퇴마단의 중심과 귀신 말살 의식에 도달한다.
- 그슨대가 선택된 이유와 로그라이크 반복의 원인을 회수한다.
- 일반 엔딩까지 연결한다.

### 공간과 동선

- 대신당 외곽, 기록고, 오방 제단, 귀록 서고, 의식 회랑, 중앙 성역.
- 앞 챕터의 기믹을 그대로 반복하지 않고 의식 형태로 압축해 재사용한다.
- 구출한 귀신 수에 따라 도움을 받는 방이 늘어난다.

### 일반 적

| 적 | 역할 |
|---|---|
| 대무당 | 방울·부채 복합 공격과 적 강화 |
| 귀록 사관 | 플레이어 장비 하나를 짧게 봉인 |
| 결계 판수 | 이동하는 정화 지대 생성 |
| 철가면 집행관 | 느린 대형 근접 압박 |
| 강화 봉인등 지기 | 여러 추적 표식을 순차 생성 |

기존 적은 단순 체력 증가판으로 대량 재사용하지 않고, 한 방에 최대 한 종류 정도를 정예 조합으로 섞는다.

### 최종 보스 — 대퇴마사

#### 1페이즈: 인간 대퇴마사

- 부채, 방울, 부적, 오방진을 사용한다.
- 지금까지 학습한 기본 회피와 지형 이동을 검사한다.

#### 2페이즈: 귀록 개방

- 현재 빌린 심장의 약점을 이용한다.
- 손각시: 머리카락 집결 봉인.
- 몽달귀신: 추가 대시 제한.
- 창귀: 원혼 스킬 봉인.
- 이후 추가 심장도 각자 대응 패턴을 설계한다.

#### 3페이즈: 빌린 모습 파괴

- 대퇴마사가 심장을 강제로 떼어내 그슨대를 검은 아이 모습으로 되돌린다.
- 귀록에는 그슨대의 이름과 약점이 없어 대퇴마사의 의식이 실패한다.
- 그슨대가 최종전 전용 거대한 검은 그림자로 변해 마지막 전투를 진행한다.
- 이 모습은 일반 캐릭터로 즉시 해금하지 않고 진엔딩 또는 후속 해금 대상으로 남긴다.

## 9. 일반 엔딩

대퇴마사를 쓰러뜨리고 귀록과 회귀진을 파괴하면 반복되던 밤이 끝난다.

1. 귀록의 이름들이 찢겨 나가며 봉인된 귀신들이 해방된다.
2. 인간과 귀신의 죽음이 더 이상 회귀하지 않는다.
3. 각 회차에서 영구 구출한 귀신들이 흉가에 모인다.
4. 흉가에 처음으로 새벽빛이 들어온다.
5. 그슨대는 빌린 모습을 잃고 검은 아이 모습으로 돌아온다.
6. 손각시가 이름을 묻지만 그슨대는 기억하지 못한다.
7. 찢어진 귀록의 마지막 빈 페이지에 희미한 아이 이름이 나타나며 종료된다.

이름과 정확한 사망 경위는 진엔딩의 핵심으로 남긴다.

## 10. 반복 회차 연출 규칙

- 최초 컷신은 한 번만 재생한다. 이후에는 1~2줄의 짧은 대화로 교체한다.
- 최초 보스 처치만 스토리 장면과 영구 해금을 제공한다. 반복 처치는 회차 보상만 제공한다.
- 인간 보스는 부활한 것이 아니라 회귀진이 밤을 되감아 사망 전 상태로 돌아간다.
- 해방한 장산범과 귀신형 보스는 이후 실제 개체가 아니라 귀록이 재현한 기록으로 표시한다.
- 구출한 귀신을 같은 감옥에서 반복 구출하지 않는다.
- NPC 대사는 최고 도달 챕터와 직전 사망 장소에 따라 달라진다.
- 도깨비상인은 귀록 바깥의 존재라 반복을 어렴풋이 기억하며 매 회차 상품을 바꾼다.

## 11. 구현 전 확정할 항목

1. `귀록`, `회귀진`, `귀문옥주`, `금위퇴마대장` 명칭.
2. 사망 시 영혼조각을 전부 잃는지 일부 보존하는지.
3. 4챕터에서 구출해 해금할 신규 심장.
4. 일반 엔딩에서 표시할 그슨대 이름의 공개 수준.
5. 최종전 전용 거대 그림자의 조작 방식.
6. 성공 회차 목표 시간을 45분과 60분 중 어디에 맞출지.
