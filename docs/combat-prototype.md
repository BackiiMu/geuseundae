# 전투·장비 플레이 프로토타입

## 조작

- A/D·방향키: 이동 / Space: 점프 / 방향+Shift: 8방향 대시
- 마우스: 조준 / 좌클릭 또는 J: 기본 공격 유지
- Q: 손각시 심장 / F: 주무기 스킬 / G: 보조무기 스킬. 없는 스킬의 안내는 숨긴다.
- Tab 또는 I: 가방. 장착·해제·교체·파기. 파기는 복구 불가 경고 후 확인해야 하며 취소가 기본이다.
- E: 포탈·상인·클리어 상자·출구 상호작용
- F8: 새 시드 1103의 선봉대장 방으로 바로 이동하는 개발용 보스 연습. 체력 60으로 시작한다.
- S/↓ + Space: 한 방향 발판에서 아래로 내려오기 (단단한 바닥은 통과하지 않음)
- N: 개발용 다음 시드 / R: 현재 방 시작 위치 / F1: 충돌 표시

가방·상점을 연 동안 전투와 이동을 멈춘다. 장비 효과와 가격은 초기 테스트 수치다.

## 장비

`equipment_db.gd`에 문서의 무기 후보와 머리·다리·발·악세서리 후보를 실행 가능한 초기 프로필로 연결했다. 주/보조 공격 간격은 독립적이며, 평타가 있는 보조만 같이 공격한다. 양손은 양쪽 칸을 점유하고 다른 손 장비를 가방으로 돌려놓는다. 심장은 손각시로 고정했고 런 중 교체하지 않는다. 악세서리는 4칸. 가방 용량은 아직 확정되지 않았으므로 임의로 12칸 제한을 추가하지 않았다.

시작 장착은 머리카락 채찍. 최초 세션에 달걀껍데기·물귀신 손·가발·꺾인 다리·젖은 꽃신을 가방에 제공해 재화 없이 장비 교체를 시험할 수 있게 했다. 영혼조각은 임의 지급하지 않는다.

무기 33개와 일반 장비 8개를 모두 실행 동작에 연결했다. 유지형 광선, 왕복 재타격, 던지기 충돌, 구슬 공전, 넋 동료, 삼키기/뱉기 등을 구현했다. 새 구현 범위와 검수 결과는 [장비 구현 기록](equipment-implementation.md)을 따른다. 최종 그림·음향·밸런스 확정은 후속 작업이다.

두억시니 주먹 30/1초, 근접 대시 피해 0.7배, 사거리 머리 조각, 대시 피해 1.5배 악세서리를 연결했다. 두억시니 3종 세트 완성 시 보조 스킬 키에 화면 내 짓누르기를 제공한다. 다른 세트의 구체적 구성/완성 효과는 정해지지 않아 임의 생성하지 않았다. 태그 시너지와 오염은 도입하지 않았다.

## 임시 적과 보스

- 무사 HP30/피해8: 바닥 추적, 0.45초 준비 후 근접 공격, 공격 후 회복.
- 도사 HP20/피해6: 거리 유지, 0.7초 준비 후 직선 부적. 벼랑으로 걷지 않으며 화면 밖이나 벽 뒤에서 공격을 시작하지 않는다.
- 선봉대장 HP420, 일반 적의 1.5배: 봉인검·부적 삼연사·바닥 충격파. 절반 체력 아래에서는 패턴 순서를 바꾼다.
- 보스는 현재 각 층의 마지막 방에 놓은 테스트 배치다. 기획의 ‘5라운드마다 보스’ 전체 진행 구조를 완성한 것은 아니다. 보스 방은 구덩이가 없는 봉인의 마당 레이아웃으로 바꾼다.
- 접촉 피해는 없고 피격 후 0.65초 보호. 대시 중 피해를 막는 임시 회피 규칙을 적용했다.
- 일반 적은 같은 표면을 걸으며 아직 층간 경로 추적은 하지 않는다. 임시 외형이다.

손각시 Q는 화면 내 적에게 머리카락을 뻗는 준비 후 끌어온다. 30초 쿨타임, 도착 후 0.35초 경직. 보스는 내려찍기 준비 중에만 저항하게 둔 임시 규칙이며 최종 확정은 아니다.

## 전투 루프

적이 남으면 문이 잠긴다. 적 처치 시 무작위 영혼조각, 보스 처치 시 확정 30조각. 영혼조각과 장비는 반경 120에서 끌려와 닿으면 한 번만 합산/가방 지급된다.

전투 방 전멸 시 중앙에 가까운 안전 바닥에 상자 또는 장비 보상 1회. 상자는 E로 열고 장비는 자동 획득한다. 방을 왕복해도 클리어 여부와 미획득 보상이 유지되며 적·보상이 다시 생성되지 않는다. 평화 상점에는 적이 없다. 구매품과 드롭이 같은 가방을 사용한다.

죽으면 마을로 돌아오며 체력과 심장 쿨타임을 회복한다. 재화·가방을 잃는 규칙이 아직 결정되지 않아 이번 프로토타입에서는 세션 내 유지한다. 앱 종료 후 세이브/복구는 아직 없다.

## 검증과 범위

- `combat_test.gd`: 장비 교체/양손·악세서리, 파기, 공격/스킬 데이터 경로, 적 처치, 피격 보호, 보상 1회·재방문 유지, 자동 획득, 보스 크기·체력·공격 생성·사망·평화 방.
- `combat_live_test.gd`: 실제 공격 입력으로 AI 적 처치, 실제 AI 공격으로 피해 받기, 보스 패턴을 물리 프레임으로 순환.
- 기존 이동·상층 동선·시드·포탈·상점·대시 검사는 적 배치와 분리해 회귀 검사.

### 2026-11-03 직접 플레이 검수

기존 네이티브 창의 크기·위치는 유지했다. 동일 Godot 프로젝트를 Web으로 내보내 640×360 화면에서 키보드·마우스로 직접 플레이했다. 화면에 보이는 정보와 실제 입력으로 진행했으며 상태 변경용 스크립트나 무적을 사용하지 않았다.

- 최종 정상 회차: 마을 → 결계 숲길 → 오래된 신당 → 봉인된 창고(상점) → 끊어진 회랑 → 봉인의 마당 → 2층 빈 행랑채.
- 가방에서 물귀신 손·가발을 장착하고, 숲길 보상 여우불을 장착했다. 전투로 11조각을 모아 상점에서 꺾인 다리를 6조각에 구매했다.
- 발판을 직접 점프해 상층 문을 사용했다. 보스에게 Q를 사용하고 대시·점프로 전투해 HP30으로 처치했다. 보스 30조각과 장비 보상을 회수한 후 E로 구간 완료, 다시 E로 2층 진입했다. F8 보스 연습 이동은 이 최종 회차에서 사용하지 않았다.
- 별도 보스 연습에서는 HP48로 처치하고 보상·출구 동작을 확인했다. 첫 일반 회차에서 처치 후 잔여 탄환에 사망한 문제를 발견해 수정했다.

수정: 배경을 전투 객체 뒤에 배치, 죽은 적 잔상 제거, 목표 방의 방 이동과 구간 출구 우선순위 분리, 상자와 출구 중복 입력 방지, 화면 밖 적 방향 표시, J 공격을 캐릭터 방향으로 통일, 여러 적 동시 심장 끌어오기 수정, 발판 하강 추가. 방 클리어 시 적 탄환을 만료시키며 이후 피해를 막는다.

상점은 네 상품 목록·등급별 색·아이콘·장착 비교·가격·별도 구매 버튼으로 구성했다. 가방은 장착 부위·아이콘 격자·설명·장착/파기를 구분했다. Noto Sans KR 폰트를 동봉하고 Web 캔버스의 잘못된 기본 해상도를 수정했다. 알림은 HP 표시와 겹치지 않도록 하단에 배치했다.

데모 밸런스: 등급별 가격 6/12/26/50조각, 평화구역 최초 방문 시 HP60 회복(재방문 반복 회복 없음), 보스 HP420·크기1.5배·시작 거리 확보·패턴별 회피 안내를 적용했다. 모두 초기 조정값이다.

검증: combat_test, combat_live_test, merchant_test, random_run_test, upper_route_test, dash_test, playability_regression_test 통과. 마지막 검사는 심장 다중 대상, 발판 하강, 바닥 충돌 복구를 확인한다. 자동 검사와 실제 플레이 결과를 구분해 기록했다.

Web 실행: http://127.0.0.1:8765/playtest/index.html (로컬 서버 실행 필요). Godot 원본은 다음 실행부터 변경 사항이 적용된다. 세이브·정식 캐릭터/몹 그림과 장비별 완성 연출은 여전히 후속 범위다.
