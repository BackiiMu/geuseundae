# 그슨대 — 심장과 신체 장비 설계

2026-11-03. 기존 게임 기획서에 대한 장비 시스템 변경안.

## 사용자가 지정한 방향

- 시작할 때 귀신의 심장을 빌리면 해당 귀신의 모습으로 변한다.
- 심장은 캐릭터의 정체성이며 HP를 결정한다.
- 장비 분류: 머리, 주무기/오른손, 보조무기/왼손, 다리, 발, 심장, 심장을 제외한 내장.
- 특정 장비에는 사용 스킬이 있고, 그 외 장비에도 능력치 또는 고유 효과가 있다.
- 손각시 심장: 낮은 HP. 시야 내 모든 적을 모아 자신의 앞으로 끌어오는 특수 스킬. 쿨타임 30초.
- 참고 게임: 던그리드.

심장 외 분류의 슬롯 개수, 내장의 세부 구분, 심장의 런 도중 교체 가능 여부는 아직 정해지지 않았다. 아래 내용은 제안이며 확정 설정과 구분한다.

## 구조 제안

심장이 귀신의 기본 모습·기본 최대 HP·고유 능력을 결정하고, 나머지 신체 장비가 그 판의 공격과 이동 방식을 바꾼다. 처음에는 심장을 거점에서 고르고 런 중에는 유지하는 방식을 권장한다. 다른 귀신의 부위를 장착해도 손각시의 정체성은 유지된다.

| 분류 | 역할 제안 | 예시 장비 및 효과 제안 |
| --- | --- | --- |
| 머리 | 감각, 공격 보조, 상태 이상 | 달걀귀신의 얼굴: 나를 바라보는 적에게 공포 축적 |
| 주무기 / 오른손 | 기본 공격의 기준 | 손각시의 머리카락: 중거리 채찍 공격 |
| 보조무기 / 왼손 | 보조 공격, 방어, 연계 | 물귀신의 손: 공격 적중 시 작은 웅덩이 생성, 내부 쿨타임 적용 |
| 다리 | 지상 이동, 자세, 대시 방식 | 몽달의 다리: 처치 후 잠시 이동속도 증가 |
| 발 | 점프, 착지, 지형 상호작용 | 젖은 꽃신: 착지 시 작은 둔화 웅덩이 |
| 심장 | 귀신의 정체성, 기본 최대 HP, 고유 능력 | 손각시 심장: 낮은 HP + 화면 내 집결, 쿨타임 30초 |
| 내장 / 심장 제외 | 자원 순환, 회복, 조건부 발동 | 아귀의 위장: 처치 시 회복, 회복량과 발동 간격은 추후 조정 |

내장은 처음에 자유 내장 슬롯 하나로 검증하고, 복수 슬롯이나 폐·간·위장별 전용 칸 여부는 이후 결정하는 안을 제안한다. 다리와 발은 각각 지상 이동과 점프/착지로 역할을 구분한다.

## 던그리드에서 가져올 설계 원칙

공식 업데이트에서 한손 무기·보조 무기·양손 무기·액세서리 수에 따른 조건을 확인할 수 있다. 장비에 귀속된 스킬과 아이템별 특수 효과도 공식 수정 내역에 등장한다. 이로부터 참고할 핵심은 장비 조합에 따라 플레이가 바뀌고, 장비의 효과가 함께 작동하는 구조다. 본작이 던그리드의 슬롯 수나 조작을 그대로 따른다는 의미는 아니다.

장비 효과는 다음처럼 나눌 수 있다.

1. 능력치: 공격력, 이동속도, 체력 등.
2. 상시 효과: 투사체 관통, 공포 상태 적에 대한 공격 변화 등.
3. 조건부 효과: 적중, 처치, 피격, 대시, 착지 후 발동. 발동 간격과 중첩 규칙 명시.
4. 사용 스킬: 버튼으로 발동하며 해당 장비에 귀속.

모든 장비에 사용 스킬을 붙일 필요는 없다. 심장 스킬은 독립 버튼을 두고, 장비 사용 스킬은 초기에는 선택한 1~2개만 단축키에 배정하는 안을 제안한다. 배정되지 않은 사용 스킬의 자동 발동은 하지 않는다. 교체를 허용한다면 재장착 시 쿨타임 초기화로 연속 사용되지 않도록 규칙이 필요하다.

장비 데이터에는 부위, 장착 조건, 능력치, 고유 효과, 발동 조건, 사용 스킬, 쿨타임, 시너지 태그를 분리해 기록한다. HP의 정확한 수치와 장비에 의한 최대 HP 보정은 테스트 후 정한다.

## 손각시 심장

확정: 낮은 HP / 시야 내 모든 적을 자신의 앞으로 집결 / 쿨타임 30초.

스킬 이름 제안: 「이리 오너라」.

의도: 적을 모아 광역 공격으로 처리하는 군중 제어형 심장. 낮은 체력과 적을 바로 앞에 모으는 위험이 함께 있다. 시야 내 적의 개수를 임의로 제한하거나 단일 대상 스킬로 바꾸지 않는다.

연출 제안: 가슴의 희미한 박동 → 화면 속 적에게 머리카락 연결 → 전방 지점으로 끌어당김 → 다발이 풀리며 공격으로 연결. 기본 공격인 머리카락 채찍과 심장 스킬은 별도 능력이다. 다른 무기를 장착해도 심장 스킬은 유지된다.

추가로 정해야 하는 판정:

- 시야의 뜻: 현재 카메라에 보이는 활성 적인지, 벽에 가려지지 않은 적인지.
- 집결 지점: 발동 시 바라보는 방향의 전방 안전 지점. 바닥·벽·낭떠러지와 적의 크기 처리.
- 다른 높이의 적: 같은 착지 지점으로 옮길지, 끌어오는 경로를 유지할지.
- 일반 적·정예·보스·고정형 적에 같은 강제 이동을 적용할지. 보스 면역은 아직 정하지 않았으며 원안의 예외를 임의로 추가하지 않는다.
- 기본 스킬 자체의 피해와 경직 유무. 초기 실험은 피해 없이 집결만 시키는 안을 제안한다.
- 무적 여부. 우선 짧은 공격 불가 경직으로 후속 공격 기회를 주는 안을 실험하되 확정하지 않는다.
- 적이 없을 때 쿨타임을 소비할지.
- 쿨타임 감소 장비와의 상호작용 및 쿨타임 시작 시점.

## 빌드 예시 — 모두 제안

손각시 심장 + 머리카락 채찍 + 물귀신의 손 + 젖은 꽃신 + 아귀의 위장.

적을 앞에 모으고 → 채찍으로 다수를 적중시키고 → 웅덩이로 발을 묶고 → 처치 회복으로 낮은 체력을 보완한다. 심장은 전투의 기회를 만들고 장비가 처리 방법을 정한다.

기존 오염 시스템과 시너지 태그는 이 장비에 붙일 수 있다. 기존 무기 2개 교체·유물 4~6개·오염 부적 1~2칸의 슬롯 구조를 이번 신체 장비와 중복 유지할지는 미정이다. 별도 유물 슬롯 추가를 전제로 하지 않는다.

## 우선 검증 범위 제안

손각시 심장 하나, 각 부위의 기본 장비, 서로 다른 두 가지 주무기, 보조 장비 하나, 다수의 적이 있는 방 하나. 낮은 체력 상태에서 30초마다 적을 모으는 선택이 실제로 재미있는지 확인한다. 이 문서는 설계 기록이며 현재 아트 미리보기에는 장비 시스템이 구현되지 않았다.
