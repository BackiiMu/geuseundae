# 영혼파편과 방 클리어 보상

## 사용자 지정 내용

- 재화 명칭은 영혼파편. 골드와 같은 용도.
- 적 처치 시 무작위로 드롭.
- 가까이 가면 플레이어에게 끌려와 자동 획득, 인벤토리의 재화 수량에 합산.
- 장비도 가까이 가면 자동으로 가방에 들어온다. 획득과 장착은 분리한다.
- 아이템 버리기는 경고와 확인 후 영구 파기한다. 바닥에 드롭하지 않으며 복구할 수 없다.
- 방 클리어 시 맵 중앙에 무작위 상자 또는 아이템 보상.

아래 수치와 아이템·등급은 제안이며 미구현이다.

## 영혼파편 제안

장비 칸을 차지하지 않는 재화 카운터로 둔다. 일반 몹 60% 확률로 1~3개, 정예는 확정 5~8개, 보스는 확정 30개를 초기 테스트 값으로 제안한다. 처치별 별도 보상 난수를 사용하며 저장 후 재입장으로 다시 굴리지 않는다.

획득 반경 120픽셀, 실제 흡수 판정은 중심 거리 16픽셀. 반경 안에 들면 부드럽게 가속해 따라오고, 실제 닿았을 때 한 번만 합산한다. 지형 밖이나 구덩이에 떨어졌을 때 회수 불능이 되지 않도록 가장 가까운 안전 표면에 놓는다. 최초에는 벽을 통과해 흡수하는 단순한 규칙을 제안한다. 흡수 중 방을 나갈 때 파편이 사라지지 않도록 방 상태를 저장한다.

사용처 후보는 상점 구매와 장비 강화/재추첨 중 우선 상점 구매부터. 사망 시 소멸하는 런 재화로 둘지, 거점까지 가져오는 영구 재화로 둘지는 미정. 자동으로 영구 성장 재화로 확정하지 않는다.

## 방 클리어 보상 제안

- 전투 방의 지정 적이 전부 쓰러지면 정확히 한 번 생성.
- 첫 입장부터 적이 없는 통로나 이미 클리어한 방은 재방문 시 보상을 생성하지 않는다.
- 가로 중앙에 가까운 **안전한 바닥** 위에 배치한다. 중앙이 구덩이나 벽이면 인접한 유효 표면으로 보정한다. 화면 중앙과 맵 중앙은 다르다.
- 우선 상자 60% / 직접 아이템 40%. 일반 상자는 장비 1개, 직접 드롭도 장비 1개. 서로 다른 수량 가치보다 발견·열기 연출을 먼저 검증한다.
- 상자는 E로 연다. 장비는 가까이 가면 자동으로 가방에 들어가며, 가방에서 직접 장착/교체한다. 자동 획득이 자동 장착을 일으키지 않는다.
- 교체한 기존 장비는 가방으로 돌아간다. 가방 12칸과 가방이 꽉 차면 신규 장비를 바닥에 남기는 규칙은 제안 단계이며, 내장 슬롯 수는 미정이다.
- 버리기는 파기 경고를 띄운 뒤 명시적으로 확인한 경우에만 영구 삭제한다. 경고에는 아이템 이름·등급과 복구 불가를 표시하고 취소를 기본 선택으로 두는 UI를 제안한다. 취소하면 유지하며, 파기한 장비는 바닥에 떨어지지 않는다. 장착 중인 아이템의 직접 파기 허용 여부는 미정이다.
- 장비 선택과 등급 추첨은 파편 드롭 및 레이아웃과 별도 시드 흐름을 사용한다.
- 시드/규칙 버전 외에 적 생존, 클리어 여부, 상자 개봉, 보상 내용과 획득 여부를 저장해야 재진입 복제가 발생하지 않는다.

## 등급 제안

| 등급 | 표시색 | 일반 방 초기 확률 | 역할 |
| --- | --- | --- | --- |
| 일반 | 회백색 | 55% | 단순하고 이해하기 쉬운 능력치 또는 효과 |
| 희귀 | 청색 | 30% | 발동 조건이나 사용 스킬로 플레이에 변화 |
| 영웅 | 보라색 | 12% | 여러 장비와 연계하는 빌드 핵심 |
| 전설 | 금색 | 3% | 독특한 공격 규칙이나 강한 고유 능력 |

아이템마다 기본 등급을 가진다. 같은 물건을 색만 바꾸어 네 등급으로 반복하는 설계는 우선 하지 않는다. 낮은 등급도 유효한 조합 효과를 가질 수 있고, 전설이라고 모든 빌드에서 무조건 우월하지 않게 한다. 효과 설명과 아이콘 표식도 함께 써 색만으로 구분하지 않는다.

오염은 등급이 아니라 장비의 별도 상태로 둔다. 정화된 도구를 들고 손해를 감수하다 오염 완료 시 효과가 바뀌는 기존 기획을 유지한다. 등급과 오염 정도를 별도 표시한다.

## 첫 장비 후보 12개 — 수치 미정

| 부위 | 아이템 | 등급 | 효과 제안 |
| --- | --- | --- | --- |
| 머리 | 헝클어진 가발 | 일반 | 머리카락 공격의 사거리 증가 |
| 머리 | 달걀귀신의 얼굴 | 영웅 | 나를 바라보는 가까운 적에게 공포 축적 |
| 오른손 | 손각시의 머리카락 | 일반 | 중거리 채찍 기본 공격 |
| 오른손 | 두억시니의 주먹 | 희귀 | 느리고 강한 내려찍기, 작은 범위 공격 |
| 왼손 | 물귀신의 손 | 희귀 | 적중 시 작은 둔화 웅덩이 생성, 발동 간격 적용 |
| 왼손 | 깨진 손거울 | 영웅 | 사용 스킬: 짧은 시간 전방 투사체 반사 |
| 다리 | 꺾인 다리 | 일반 | 이동속도 증가 |
| 다리 | 몽달의 다리 | 희귀 | 처치 후 잠시 이동속도와 공격속도 증가, 중첩 상한 적용 |
| 다리 | 한쪽 꽃신 | 일반 | 착지 시 작은 범위 밀치기, 발동 간격 적용 |
| 다리 | 젖은 꽃신 | 희귀 | 대시가 지나간 바닥에 짧게 유지되는 둔화 물자국 |
| 내장 | 아귀의 위장 | 영웅 | 처치 시 소량 회복, 발동 간격 적용 |
| 내장 | 끊이지 않는 원한의 폐 | 전설 | 사용 스킬: 근처 공포 상태 적을 통해 저주 파동이 연쇄 확산 |

오른손/왼손 장비 호환성, 장비 사용 스킬 단축키 수, 공격속도 등 실제 수치는 후속 검증한다. 시작 심장은 런 정체성이므로 일반 방의 드롭 풀에서는 우선 제외하는 안을 제안한다. 심장 해금/중도 교체 허용은 별도 결정 사항이다.

예시 빌드: 손각시 심장으로 적 집결 → 두억시니 주먹의 범위 공격 → 아귀 위장의 처치 회복. 이는 장비가 바뀌어도 심장 스킬은 유지된다는 구조를 시험한다.

## 첫 구현 범위 제안

영혼파편 드롭/자석 획득 → 전투방 클리어 1회 판정 → 안전 위치 보상 → 상자 열기/장비 비교·교체 순서. 먼저 일반·희귀 아이템 6개로 검증하고, 후보 12개 전체와 영웅/전설은 후속으로 늘린다. 적 처치와 전투 시스템이 아직 없으므로 현재 게임에 작동하는 드롭/클리어 보상을 구현한 상태는 아니다.
