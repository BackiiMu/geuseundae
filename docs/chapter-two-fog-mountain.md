# 2챕터 — 안개 낀 산

## 확정 방향

- 2챕터 배경은 달빛이 거의 없는 한국 산악 지형이다.
- 여러 겹의 산 능선, 절벽, 뒤틀린 소나무, 폐허가 된 작은 정자와 돌계단을 원경에 배치한다.
- 화면 전체에는 아주 옅은 청회색 안개가 흐르지만 캐릭터, 적, 발판의 실루엣은 선명하게 유지한다.
- 전경 타일과 충돌 발판은 배경 이미지에 포함하지 않고 별도 레이어로 제작한다.
- 장산범이 가까워지는 구간에서는 안개 밀도를 높여 실루엣이 먼저 드러나는 연출을 사용한다.

## 1차 배경

- 파일: `godot/assets/environment/chapter2/fog-mountain-background-v1.png`
- 규격: 2172×724, 불투명 원경 이미지
- 용도: 여러 화면을 가로지르는 최후방 패럴랙스 레이어
- 색상: 짙은 남청색, 청회색, 탁한 비취색
- 현재 단계: 배경 원경 1차 시안. 움직이는 중경·전경 안개와 충돌 타일은 별도 제작한다.

## 게임 적용 상태

- 2층부터 자동으로 `2챕터 · 안개 낀 산` 배경과 산악 방 이름을 사용한다.
- 화면 전체에 약한 청회색 안개막과 속도가 다른 세 줄의 안개가 흐른다. HUD는 안개보다 위에 표시한다.
- 일반 전투 방에는 창귀 잔혼, 미혹불, 호식총 원귀, 산호랑이가 시드에 따라 배치된다.
- 일부 방에는 장산범의 그림자가 정예로 등장한다.
- 마지막 방의 장산범은 각 체력을 완전히 소진해야 넘어가는 3페이즈 보스다. 1페이즈는 플레이어와 같은 모습(HP 260)으로 기본 할퀴기만 사용하고, 2페이즈는 조금 커진 장산범의 그림자(HP 450), 3페이즈는 그림자의 약 2배 크기인 흰 몸·붉은 얼굴의 장산범(HP 850)이다. 2·3페이즈는 할퀴기, 목소리 탄막, 흰 번개 돌진을 순환한다.
- 각 페이즈 처치 시 전투와 화면을 잠시 멈추고 안개가 보스를 완전히 가린다. 안개 안에서 다음 외형과 새 체력으로 교체한 뒤 안개가 걷히며 전투를 재개한다.
- 1챕터 선봉대장 처치는 2챕터 길만 열고, 장산범 장비와 창귀 심장 해금은 실제 장산범 처치 시에만 발생한다.
- 자동 검사: `godot/tests/chapter_two_test.gd`
- 렌더링 검수: `docs/reviews/chapter2/`

## 장산범 보스 아트

- 파일: `godot/assets/actors/source/jangsanbeom-v1.png`
- 생성 원본: `godot/assets/actors/concepts/jangsanbeom-boss-atlas-v1.png`
- 규격: 1536×1024, 8열 × 4행, 프레임당 192×256
- 외형: 호랑이형 네발 골격, 길고 고운 흰 털, 털 사이로 선명하게 드러나는 진홍색 얼굴·귀·앞발, 검은 입과 송곳니.
- 행 구성: idle 8, run 8, 공격 8, 피격·포효·사망 8.
- 일반 호랑이와 구분하기 위해 주황색 털과 일반적인 줄무늬는 사용하지 않는다.
- 장산범은 전통 설화집에 확고하게 채록된 존재라기보다 현대 도시괴담 성격이 강하므로, 한 가지 정답을 주장하지 않고 반복되는 대중적 특징을 게임의 기준 외형으로 삼는다.

- 게임용: `godot/assets/actors/source/changgui-remnant-v1.png`

## 생성 프롬프트 요약

기존 흉가 환경 아틀라스와 실제 게임 화면을 스타일·스케일 참고로 사용했다. 한국의 안개 낀 산을 매우 넓은 횡스크롤 도트 배경으로 구성하고, 겹친 산 능선과 절벽, 소나무, 오래된 돌계단과 작은 폐허를 배치했다. 캐릭터·몬스터·UI·글자·충돌 발판은 제외하고 아래쪽 전투 가독성을 확보했다.
