# 그슨대 몬스터 공격 이펙트

공통 흐름: 멈춤 → 선딜(자세 + 바닥의 범위 점선) → 공격 → 회복. 모든 시트는 반짝임·광 없는 무광이다(밝은 부분 상한을 눌렀다).

## 폴더
- fx: 이펙트만 있는 시트 (투명 PNG + Aseprite JSON). 원점은 몬스터의 발. 몬스터의 자식 노드로 붙이고 좌우 반전을 따라가게
- preview: 색만 입힌 대역 몸과 플레이어 자리 허수아비가 함께 있는 확인용 시트

## 파일
| 몬스터 | 공격 | 시트 |
| --- | --- | --- |
| 퇴마 무사 | 부적검 근접 베기 | musa-slash |
| 부적 도사 | 부적 투사체 (시전·명중 이펙트 없음) | talisman-shot (반복, 직선 이동) |
| 목탁 승려 | 목탁 강타 · 먼지 충격파 | monk-moktak (판정 중심이 몸 앞 40) |
| 퇴마단 선봉대장 | 넓은 검 베기 | captain-sweep |
| 퇴마단 선봉대장 | 강한 내려베기 | captain-cleave |
| 퇴마단 선봉대장 | 돌진 | captain-charge-fx (몸에 붙임, 이동은 게임이), 미리보기 captain-charge |

| 창귀 잔혼 | 발톱 돌진 | changgui-claw (몸에 붙임) |
| 산호랑이 | 발톱 돌진 | tiger-claw (몸에 붙임) |
| 장산범의 그림자 | 먹빛 발톱 돌진 | shadow-claw (몸에 붙임) |
| 미혹불 | 도깨비불 시전 | mihokbul-cast (투사체는 기존 spirit 선) |
| 호식총 원귀 | 바닥에서 솟는 손 | hosikchong-erupt (판정 중심이 몸 앞 30, 반경 92) |

2챕터 시트는 `combat_enemy.gd`의 `ATTACK_VFX`로 연결한다. 원점은 모두 발이고 판정 원(`area_effect`)에 맞춰 크기를 정했다.
