# 그슨대 1장 몬스터 공격

공통 흐름: 멈춤 → 선딜(자세 + 무기의 별빛 + 바닥의 범위 점선) → 공격 → 회복(입김)

## 폴더
- fx: 이펙트만 있는 시트 (투명 PNG + Aseprite JSON). 원점은 몬스터의 발. 몬스터의 자식 노드로 붙이고 좌우 반전을 따라가게
- preview: 색만 입힌 대역 몸과 플레이어 자리 허수아비가 함께 있는 확인용 시트

## 파일
| 몬스터 | 공격 | 시트 |
| --- | --- | --- |
| 퇴마 무사 | 부적검 근접 베기 | musa-slash |
| 부적 도사 | 부적 투사체 | talisman-cast (손에 붙임), talisman-shot (반복, 직선 이동), talisman-hit / 미리보기 dosa-talisman |
| 목탁 승려 | 목탁 강타 | monk-moktak |
| 퇴마단 선봉대장 | 넓은 검 베기 | captain-sweep |
| 퇴마단 선봉대장 | 강한 내려베기 | captain-cleave |
| 퇴마단 선봉대장 | 돌진 | captain-charge-fx (몸에 붙임, 이동은 게임이), 미리보기 captain-charge |

## 타이밍 (초, 시트 시작 기준)
| 공격 | 멈춤 | 선딜 | 공격 | 회복 | 타격 시점 |
| --- | --- | --- | --- | --- | --- |
| 퇴마 무사 · 부적검 베기 | 0 ~ 0.15 | 0.15 ~ 0.75 | 0.75 ~ 0.86 | 0.86 ~ 1.55 | 0.80 |
| 부적 도사 · 부적 투사체 | 0 ~ 0.10 | 0.10 ~ 0.75 | 0.75 ~ 1.25 | 0.85 ~ 1.25 | 1.23 |
| 목탁 승려 · 목탁 강타 | 0 ~ 0.15 | 0.15 ~ 1.15 | 1.15 ~ 1.28 | 1.28 ~ 2.20 | 1.22 |
| 퇴마단 선봉대장 · 넓은 베기 | 0 ~ 0.10 | 0.10 ~ 0.50 | 0.50 ~ 0.62 | 0.62 ~ 1.15 | 0.56 |
| 퇴마단 선봉대장 · 내려베기 | 0 ~ 0.10 | 0.10 ~ 0.85 | 0.85 ~ 1.22 | 0.98 ~ 1.60 | 0.92 |
| 퇴마단 선봉대장 · 돌진 | 0 ~ 0.10 | 0.10 ~ 0.75 | 0.75 ~ 1.03 | 1.03 ~ 1.55 | 0.95 |
- 돌진: 선딜이 끝나면 0.28초 동안 120px 직선 이동
- 선봉대장은 게임에서 1.5배 크기이므로 시트도 1.5배로 키워 사용
