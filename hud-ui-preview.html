HUD UI 시안 · HP 바 · 대시 게이지 · 가방 · 설정

기존 도트 UI 부품(godot/assets/ui/hud의 HP 프레임·가방·설정 아이콘, ui/modular의 패널·버튼·명판)과 같은 재질로 맞췄습니다. 게임에는 적용하지 않은 미리보기입니다. 모든 조각은 눌러 보거나 슬라이더로 움직여 볼 수 있습니다.

1. 게임 화면 배치 (768×432, 1:1)

왼쪽 위에 HP 바와 대시 게이지, 오른쪽 위에 가방·설정. 가방과 설정은 클릭해 보세요.

Q 심장 준비 | 방향키 공격 · J/좌클릭 공격

2. HP 바

기존 hp-frame-v1.png(옻칠 틀·놋쇠 모서리·붉은 매듭) 안쪽 칸에 핏빛 게이지를 채웁니다. 피해를 입으면 흰 번쩍임 뒤 옅은 잔상이 천천히 줄고, 25% 이하에서는 깜빡입니다. 칸 나눔 없이 HP 비율만큼 매끄럽게 줄고 늡니다.

HP 60 최대 60

3. 대시 충전 게이지

기본 1회이고 심장·장비로 늘어납니다(몽달 3회). 엽전 한 닢이 대시 1회이며, 쓰면 비고 0.65초 동안 아래에서 위로 놋쇠색이 차오릅니다(게임의 충전 간격과 같음). 개수가 늘면 판이 옆으로 길어집니다.

최대 1회

4. 가방 아이콘 (닫힘 / 열림)

닫힘은 기존 bag-icon-v1.png, 열림 두 장(반쯤·활짝)은 같은 주머니를 코드로 그린 초안입니다. 클릭하면 열리고 다시 클릭하면 닫히며(약 0.1초 간격 3컷), 개수 표시와 새 아이템 점을 붙일 수 있습니다.

닫힘 → 반쯤 → 열림
클릭해서 열고 닫기 (Tab / I)
새 아이템 표시

5. 설정

설정 아이콘은 기존 settings-icon-v1.png입니다(마우스를 올리면 살짝 돌고, 열리면 더 돕니다). 패널은 인벤토리와 같은 옻칠 패널·종이 명판·붉은 버튼을 썼습니다. 항목은 제안이며 게임에 아직 없는 기능도 있습니다.
